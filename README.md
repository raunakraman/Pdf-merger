# 📄 PDF Merger

A simple and easy-to-use **PDF Merger** project that allows users to combine **two or three PDF files into a single PDF document**.

This project is designed to make merging PDF documents quick, simple, and convenient without requiring users to manually copy or rearrange pages.

## 🚀 Features

* 📑 Merge**2** or **3** PDF files into one PDF
* 🔄 Combine PDFs in the selected order
* ⚡ Fast and simple PDF merging
* 🖥️ Easy-to-use interface
* 📂 Upload PDF files directly
* 📥 Download the merged PDF
* 🔒 Files can be processed locally depending on the project implementation
* 🎯 Simple and beginner-friendly project

## 🛠️ Technologies Used

The technologies used in this project include:

**phyton and it's libraries**
* **tkinter** – Structure of the application

## ⚙️ How It Works

1. Open the PDF Merger application.
2. Select **two or three PDF files**.
3. Choose the order in which the PDFs should be merged.
4. Click the **Merge PDF** button.
5. The application combines the selected PDF files.
6. Download the newly generated merged PDF.

### Example

If the user selects:

```text
PDF 1 → Resume.pdf
PDF 2 → Certificate.pdf
PDF 3 → Marksheet.pdf
```

The application generates:

```text
Name you provide.pdf
```

containing:

```text
Resume.pdf
        ↓
Certificate.pdf
        ↓
Marksheet.pdf
```
